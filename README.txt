# DRishti: AI-Powered Automated Diabetic Retinopathy Screening System

## Smart India Hackathon (SIH) 2026

### Overview

DRishti is an AI-powered automated diabetic retinopathy (DR) screening system developed using MATLAB and Simulink. The system assists in the early detection of diabetic retinopathy by analyzing retinal fundus images and providing explainable AI-based predictions along with automated clinical reports.

The solution is designed to support large-scale screening programs, especially in rural and resource-constrained healthcare environments.

---

## Problem Statement

Diabetic Retinopathy is one of the leading causes of preventable blindness among diabetic patients. Early detection is critical, but access to ophthalmologists is limited in many regions.

This project aims to provide:

- Automated retinal image analysis
- Early DR detection
- Explainable AI predictions
- Telemedicine-ready workflow
- Faster screening and triage
